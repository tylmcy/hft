二、成交后数据流 (Trade Flow) - V9 内存主存储

下单流程关键点

  • • 前端校验: 价格/数量格式、涨跌停限制
  • • REST API: POST /api/order
  • • 风控检查: 资金充足性O(1)、持仓限额
  • • compute原子冻结: Entry级别锁，多线程安全
  • • Chronicle Queue: 零拷贝写入，延迟<10μs
  • • 撮合引擎: 价格优先时间优先
  • • 总延迟: 4-8ms (P99<15ms)

成交后处理

  • • ORDER_UPDATE: PENDING→NEW状态
  • • TRADE: compute原子清算
  • • 幂等检查: putIfAbsent(tradeId)
  • • 账户更新: balance、available变动
  • • 持仓更新: quantity、available变动
  • • T+1规则: 当日买入不可卖出
  • • 异步持久化: 不阻塞主链路

WebSocket推送

  • • ORDER_UPDATE: 订单状态变更
  • • TRADE_REPORT: 成交回报
  • • POSITION_UPDATE: 持仓变动
  • • BALANCE_UPDATE: 资金变动
  • • 前端: Zustand状态自动更新
  • • 用户: 无需刷新页面

性能指标

  • • 风控检查: ~0.1ms (内存查表)
  • • 队列写入: ~0.01ms (零拷贝)
  • • 撮合处理: ~0.01ms (单线程)
  • • 清算处理: ~0.05ms (内存操作)
  • • WebSocket推送: ~1-2ms
  • • 端到端: 4-8ms (P99<15ms)
