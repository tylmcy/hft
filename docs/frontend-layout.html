总览页面 (Overview)

  • 指数行情栏: 上证、深证、创业板、科创50、沪深300、IF主力
  • 上涨Top5: 涨幅排序，实时更新
  • 下跌Top5: 跌幅排序，实时更新
  • 成交量Top5: 成交额排序
  • 交易所品种涨幅: 上交所、深交所、中金所、上交所期权
  • 数据来源: 内部撮合引擎（MatchingEngine OrderBook聚合）
  • 注: 总览页面指数行情可接入外部数据源（如新浪）仅供展示

个人中心 (Profile)

  • 用户信息: 头像、用户名、邮箱、注册时间
  • 账户统计: 总资产、API Key数量、交易统计
  • API Key管理: 创建、查看、删除
  • Key类型: 只读Key / 交易Key
  • 权限控制: 交易Key可指定可交易品种
  • HMAC签名认证: API Key + Secret Key

OpenAPI接口

  • WebSocket: /openapi/ws 行情订阅
  • 账户查询: GET /openapi/account
  • 持仓查询: GET /openapi/positions
  • 下单: POST /openapi/orders
  • 撤单: DELETE /openapi/orders/{id}
  • 当前委托: GET /openapi/orders/active

API Key权限

  • 只读Key: 行情订阅、账户查询、持仓查询、委托查询
  • 交易Key: 只读权限 + 下单、撤单
  • 品种限制: 交易Key可指定股票/期货/期权
  • 认证方式: HMAC-SHA256签名
  • 请求Header: X-API-Key, X-Timestamp, X-Signature
