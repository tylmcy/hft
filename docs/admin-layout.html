管理端界面设计 | 入金上账、账户管理、订单监控、资金流水、品种管理、交易日历

Admin Dashboard (管理端主页面)
Deposit Modal (入金处理弹窗)
Instrument Management (品种管理页面)
Trading Calendar (交易日历管理)
Cashflow Management (资金流水管理)

系统概览 (Dashboard)

  • 在线用户数: 实时统计
  • 今日订单数: 成交率统计
  • 今日成交额: 金额统计
  • 系统TPS: 实时吞吐量
  • P99延迟: 性能监控
  • 待处理入金: 需及时处理

入金管理 (Deposit)

  • 待处理入金列表: 实时更新
  • 入金审批: 批准/拒绝
  • 实际入金金额: 可调整
  • 审批备注: 可选填写
  • 历史记录: 已处理入金
  • 入金来源: 银行转账备注

账户管理 (Accounts)

  • 账户列表: 分页查询
  • 账户状态: 正常/预警/冻结
  • 资产统计: 总资产/持仓市值
  • 风险监控: 风险度百分比
  • 盈亏统计: 实时盈亏
  • 导出功能: Excel导出

品种管理 (Instruments)

  • 品种类型: 股票/期货/期权
  • 品种状态: 交易中/停牌/到期
  • 合约参数: 最小价位/乘数/保证金
  • 涨跌停限制: 百分比设置
  • 批量导入: CSV导入
  • 停牌/复牌: 状态切换

资金流水 (Cashflow)

  • 流水类型: 入金/出金/买入/卖出/手续费/印花税/保证金
  • 用户筛选: 按账户ID/用户名查询
  • 时间筛选: 今日/本周/本月/自定义
  • 关联查询: 关联订单/成交ID
  • 统计汇总: 入金/出金/手续费/印花税/净流入
  • 导出功能: Excel导出

交易日历 (Calendar)

  • 日历视图: 月历展示
  • 交易日标记: 绿色高亮
  • 休市日标记: 红色显示
  • 假期设置: 添加假期
  • 交易时段: 09:30-11:30, 13:00-15:00
  • 配置导入导出: JSON/CSV

系统监控 (Monitoring)

  • JVM状态: 堆内存/GC/线程
  • Chronicle状态: Queue/Map
  • 撮合引擎: 延迟/订单簿深度
  • WebSocket: 连接数/推送速率
  • 磁盘使用: 存储监控
  • 实时刷新: 5秒间隔
