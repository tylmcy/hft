单线程Worker批量处理 · 内存主存储 · CQ事件流 · 三层幂等 · RPO=0

IO 线程 (HTTP/WebSocket)

  • • HTTP: Virtual Threads (unlimited), REST API 请求处理
  • • 写入 CQ 后 CompletableFuture.get(5s) 同步等待
  • • WebSocket: Netty EventLoop (8 threads), 实时推送
  • • 非阻塞 write, 行情/订单/成交/账户变更推送
  • • 心跳 ping/pong 30s, JWT token 认证

AccountWorker (单线程批量)

  • • 1 线程串行处理, 无锁无并发问题
  • • 批量读取 account_input CQ (50/batch)
  • • 冻结/解冻资金持仓, 结算转账 (内存操作)
  • • 批量写 matching_input + account_output CQ
  • • CompletableFuture.complete() 唤醒 HTTP 线程
  • • WebSocket push (Netty non-blocking)

MatchingEngine (单线程批量)

  • • 1 线程串行处理, 多 Symbol 订单撮合
  • • 批量读取 matching_input CQ (50/batch)
  • • 价格优先时间优先撮合, 更新 OrderBook
  • • 批量写 matching_output CQ (TradeEvent)
  • • 五档行情推送 + K线聚合
  • • processed_order_ids 幂等检查

ClearingWorker (单线程批量100)

  • • 1 线程串行处理, 批量 100/batch
  • • 批量读取 matching_output CQ
  • • 更新订单状态, 计算佣金/退款
  • • 生成 SETTLEMENT/UNFREEZE 事件
  • • 批量写 account_settlement CQ
  • • putIfAbsent() TradeId 幂等保证

辅助线程 (5个)

  • • SnapshotWorker: 定时60s, SNAPSHOT事件→CM快照
  • • PhaseManager: 交易阶段切换, PHASE_CHANGE
  • • RiskMonitor: 风险监控, 强平触发 (期货/期权)
  • • LifecycleManager: 状态机, 四阶段恢复协调
  • • AsyncPersistence: matching_output→H2 批量写

线程总数: 15+

  • • HTTP Virtual Threads: N (unlimited)
  • • WebSocket Netty EventLoop: 8
  • • AccountWorker: 1
  • • MatchingEngine: 1
  • • ClearingWorker: 1
  • • Snapshot/Phase/Risk/Lifecycle/Async: 5
  • • 总计: 15+ (固定线程 16 + HTTP虚拟线程)
