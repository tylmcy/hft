A股交易系统 Architecture

单机单JVM · Chronicle Queue · 100K TPS · P99 ≤ 15ms · 阿里云 8C16G · ZGC

性能指标

  • • 报撤单吞吐量 ≥ 100,000 TPS
  • • 端到端延迟 P99 ≤ 15ms
  • • 撮合延迟 < 10μs
  • • Chronicle Queue写入 < 10μs
  • • WebSocket推送 < 2ms

核心链路

  • • 订单 → Chronicle Q → 撮合 → Chronicle Q → 清算
  • • 每个标的独立撮合线程，无锁竞争
  • • 账户/持仓全内存操作，O(1)查询
  • • 异步批量持久化到H2，不阻塞主链路

部署配置

  • • 阿里云 8C16G 单机单JVM
  • • JVM堆 10GB + 直接内存 4GB
  • • ZGC (Generational), 暂停 <1ms
  • • 行情: 新浪财经爬取 (每3秒)
  • • 业务: A股 + IF期货 + 50ETF期权
