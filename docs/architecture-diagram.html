A股交易系统 Architecture V9

单JVM · 内存主存储 · 批量处理100K TPS · RPO=0 · 快照+CQ增量恢复

性能指标

  • • 吞吐量 ≥ 100,000 TPS
  • • HTTP返回P99 ≤ 5ms
  • • 端到端P99 ≤ 15ms
  • • 批量处理: 50事件/批次
  • • 快照间隔: 60秒

数据存储

  • • 主存储: ConcurrentHashMap (内存)
  • • 事件流: Chronicle Queue
  • • 快照: Chronicle Map
  • • 历史: H2 Database
  • • RPO = 0 (CQ持久化)

快照机制

  • • SNAPSHOT事件触发快照
  • • Worker处理时自然暂停
  • • account_snapshot_{cq_idx}.dat
  • • orderbook_snapshot_{cq_idx}.dat
  • • clearing_index.dat每批次更新

线程模型

  • • HTTP: Tomcat虚拟线程
  • • AccountWorker: 单线程批量
  • • MatchingEngine: 单线程批量
  • • ClearingWorker: 单线程批量
  • • SnapshotWorker: 定时触发
