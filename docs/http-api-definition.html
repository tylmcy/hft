🔐 认证模块

POST /api/auth/login 认证
用户登录，返回 JWT Token

请求参数

{ "username": "string", // 用户名 "password": "string" // 密码 }

响应参数

{ "code": 0, "message": "success", "data": { "token": "eyJhbGciOiJIUzI1NiIs...", // JWT Token "expireTime": 1716307200000, // 过期时间戳 "accountId": 10001, // 账户ID "username": "trader01" // 用户名 } }
POST /api/auth/logout 认证
用户登出，清除 Token

请求头

Authorization: Bearer <token>

响应参数

{ "code": 0, "message": "success" }

📝 订单模块

POST /api/orders 订单
下单接口，支持股票/期货/期权。同步返回orderId（CompletableFuture等待冻结完成），异步成交。

请求参数

{ "symbol": "600000", // 标的代码 "side": "buy", // 方向: buy/sell (股票) // open_long/open_short/close_long/close_short (期货) // call/put (期权) "orderType": "limit", // 订单类型: limit/market/fak/fok "price": 1000, // 价格 (分)，市价单可不传 "quantity": 100, // 数量 "accountId": 10001 // 账户ID (可选，默认当前账户) }

响应参数

{ "code": 0, "message": "success", "data": { "orderId": 100001, "symbol": "600000", "side": "buy", "orderType": "limit", "price": 1000, "quantity": 100, "status": "pending", // pending/partial_filled/filled/cancelled/rejected "createTime": 1716307200000 } }
DELETE /api/orders/{orderId} 订单
撤单接口

路径参数

参数类型说明
orderIdlong订单ID

响应参数

{ "code": 0, "message": "success", "data": { "orderId": 100001, "status": "cancelled", "cancelTime": 1716307200000 } }

🔄 接口调用流程图

阶段 1: 登录初始化

1
POST /api/auth/login
用户输入用户名密码 → 调用登录接口 → 获取 JWT Token → 存储到 localStorage
2
GET /api/account/info
登录成功后立即调用 → 初始化 AccountBar 导航栏账户信息
3
GET /api/market/watchlist
获取自选股列表 → 初始化 MarketList 自选股区域
4
WebSocket 连接
建立 WebSocket 连接 → 订阅行情/订单/成交推送

阶段 2: 市场浏览

1
GET /api/market/symbols?keyword=xxx&sortBy=change_pct
搜索/筛选股票 → 更新 MarketList 列表
2
POST /api/market/watchlist
点击"添加自选" → 添加到自选股列表
3
WebSocket 订阅 symbol 行情
点击股票 → 订阅 K线/订单簿/成交明细 → 实时更新

阶段 3: 下单交易

1
GET /api/account/info (缓存)
下单面板显示可用资金 → 从缓存读取 (定期刷新)
2
POST /api/orders
填写价格/数量 → 点击买入/卖出 → 提交订单
3
WebSocket 推送订单状态
订单状态变化 → WebSocket 推送 → 更新 OrderTable
4
WebSocket 推送成交
成交回报 → WebSocket 推送 → 更新账户/持仓/成交明细

阶段 4: 撤单操作

1
DELETE /api/orders/{orderId}
点击"撤单"按钮 → 调用撤单接口 → 返回撤单结果
2
WebSocket 推送撤单结果
撤单成功 → WebSocket 推送 → 更新订单状态/解冻资金

阶段 5: 历史查询

1
GET /api/orders/active
切换到"当前委托" Tab → 加载当前委托列表
2
GET /api/trades?startDate=xxx&endDate=xxx
切换到"历史成交" Tab → 加载历史成交记录
3
GET /api/account/cashflow?type=trade
切换到"资金流水" Tab → 加载资金流水记录
4
GET /api/account/positions
切换到"持仓管理" Tab → 加载持仓列表

🔌 WebSocket 模块

WS ws://host:port/ws WebSocket
WebSocket 连接端点，用于实时行情推送、订单状态推送、成交推送

连接建立

// 连接 URL ws://host:port/ws?token=<jwt_token> // 连接成功响应 { "type": "connected", "clientId": "client-xxx", "serverTime": 1716307200000 }

心跳机制

// 客户端发送 (每30秒) { "type": "ping", "timestamp": 1716307200000 } // 服务端响应 { "type": "pong", "timestamp": 1716307200000 }

订阅消息

SUB 订阅行情/订单/成交 WebSocket

订阅行情快照

// 订阅请求 { "type": "subscribe", "channel": "market_snapshot", "symbols": ["600000", "600519"] } // 订阅成功响应 { "type": "subscribed", "channel": "market_snapshot", "symbols": ["600000", "600519"] }

订阅 K 线数据

// 订阅请求 { "type": "subscribe", "channel": "kline", "symbol": "600000", "period": "1m" // 1m/5m/15m/30m/60m/d/w/m }

订阅订单簿 (Level 2)

// 订阅请求 { "type": "subscribe", "channel": "orderbook", "symbol": "600000", "depth": 10 // 档位深度: 5/10/20/50 }

订阅订单状态

// 订阅请求 (订阅当前账户所有订单) { "type": "subscribe", "channel": "order_update", "accountId": 10001 }

订阅成交推送

// 订阅请求 { "type": "subscribe", "channel": "trade_update", "accountId": 10001 }

订阅账户资金变动

// 订阅请求 { "type": "subscribe", "channel": "account_update", "accountId": 10001 }

取消订阅

UNSUB 取消订阅 WebSocket
// 取消订阅请求 { "type": "unsubscribe", "channel": "market_snapshot", "symbols": ["600000"] } // 取消成功响应 { "type": "unsubscribed", "channel": "market_snapshot", "symbols": ["600000"] }

推送消息类型

PUSH 行情快照推送 行情
{ "type": "market_snapshot", "data": { "symbol": "600000", "symbolName": "浦发银行", "price": 1050, // 当前价 (分) "open": 1025, // 开盘价 (分) "high": 1060, // 最高价 (分) "low": 1020, // 最低价 (分) "preClose": 1025, // 昨收 (分) "change": 25, // 涨跌 (分) "changePct": 2.44, // 涨跌幅 (%) "volume": 12345678, // 成交量 "amount": 12345678900, // 成交额 (分) "bidPrice1": 1049, // 买一价 (分) "bidVolume1": 5000, // 买一量 "askPrice1": 1050, // 卖一价 (分) "askVolume1": 3000, // 卖一量 "timestamp": 1716307200000 } }
PUSH K线数据推送 行情
{ "type": "kline", "data": { "symbol": "600000", "period": "1m", "time": 1716307200000, "open": 1050, "high": 1055, "low": 1048, "close": 1052, "volume": 12345, "amount": 12345678 } }
PUSH 订单簿推送 (Level 2) 行情
{ "type": "orderbook", "data": { "symbol": "600000", "bids": [ // 买盘 [价格, 数量] [1050, 5000], [1049, 8000], [1048, 12000] ], "asks": [ // 卖盘 [价格, 数量] [1051, 3000], [1052, 6000], [1053, 10000] ], "timestamp": 1716307200000 } }
PUSH 订单状态推送 订单
{ "type": "order_update", "data": { "orderId": 100001, "symbol": "600000", "symbolName": "浦发银行", "side": "buy", "orderType": "limit", "price": 1000, "quantity": 100, "filledQuantity": 50, "status": "partial_filled", // pending/partial_filled/filled/cancelled/rejected "message": "", // 错误信息 "updateTime": 1716307200000 } }
PUSH 成交推送 订单
{ "type": "trade_update", "data": { "tradeId": 200001, "orderId": 100001, "symbol": "600000", "symbolName": "浦发银行", "side": "buy", "price": "1000", "quantity": "50", "amount": "50000", // 成交金额 (分) "commission": "25", // 手续费 (分)，仅计算手续费 "tradeTime": "1716307200000" } }
PUSH 账户资金变动推送 账户
{ "type": "account_update", "data": { "accountId": "10001", "balance": "123456700", // 总资金 (分) "available": "56789000", // 可用资金 (分) "frozen": "100000", // 冻结资金 (分) "marginFrozen": "0", // 保证金冻结 (分)，期货/期权专用 "orderFrozen": "100000", // 订单冻结 (分)，股票专用 "marketValue": "78901200", // 持仓市值 (分) "totalAsset": "123456700", // 总资产 (分) "unrealizedPnl": "1234500", // 浮动盈亏 (分) "delta": "-105000", // 变动金额 (分) "reason": "ORDER_FREEZE", // 变动原因 "updateTime": "1716307200000" } }
PUSH 持仓变动推送 账户
{ "type": "position_update", "data": { "accountId": 10001, "symbol": "600000", "symbolName": "浦发银行", "quantity": 1000, // 持仓数量 "available": 1000, // 可用数量 "frozen": 0, // 冻结数量 "costPrice": 1000, // 成本价 (分) "currentPrice": 1050, // 当前价 (分) "marketValue": 105000, // 市值 (分) "unrealizedPnl": 5000, // 浮动盈亏 (分) "updateTime": 1716307200000 } }

🔌 WebSocket 交互流程图

阶段 1: 连接建立

1
ws://host:port/ws?token=xxx
前端使用 JWT Token 建立 WebSocket 连接 → 服务端返回 connected 消息
2
subscribe: market_snapshot (自选股列表)
订阅自选股行情快照 → 实时推送行情变动 → 更新 MarketList 组件
3
subscribe: order_update + trade_update + account_update
订阅订单/成交/账户变动 → 实时推送交易状态 → 更新订单表格和账户信息

阶段 2: 行情订阅

1
unsubscribe: market_snapshot (旧股票)
用户切换股票 → 先取消旧股票订阅
2
subscribe: kline + orderbook (新股票)
订阅新股票 K线 + 订单簿 → 实时推送 → 更新 ChartPanel 和 DepthPanel
3
PUSH: kline / orderbook
服务端持续推送 K线和订单簿数据 → 前端实时渲染

阶段 3: 交易推送

1
POST /api/orders (HTTP 下单)
用户下单 → HTTP 请求 → 返回 orderId (pending 状态)
2
PUSH: order_update (partial_filled)
订单部分成交 → WebSocket 推送订单状态 → 更新 OrderTable
3
PUSH: trade_update
成交回报 → WebSocket 推送成交明细 → 更新成交列表
4
PUSH: account_update + position_update
账户资金/持仓变动 → WebSocket 推送 → 更新 AccountBar 和持仓面板

阶段 4: 心跳保活

1
ping → pong (每 30 秒)
前端定时发送 ping → 服务端返回 pong → 保持连接活跃
2
断线重连
连接断开 → 自动重连 → 重新订阅所有 channel
